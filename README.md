# 조사 1팀 지도 제작자 홈페이지

첨부된 CYOA 합류 기록을 바탕으로 만든 별도 GitHub Pages 홈페이지입니다. `index.html`은 연구청 기록 단말 형식의 접속 화면이고 `profile.html`은 인물 기록입니다. 이름과 실제 프로필 사진은 아직 정해지지 않아 이름은 ‘미정’, 인물 이미지는 외형을 확정하지 않는 뒷모습 삽화로 표시했습니다. 나이는 기록에 있는 그대로 23~29세, 성별은 남성입니다.

접속 화면과 인물 기록은 라이카 홈페이지의 문서형 레이아웃을 기준으로 맞추고, 이 인물에는 청록색 강조색을 사용했습니다. 기존 서사와 능력 설명은 그대로 유지했습니다.

서사의 기준은 산과 숲 가까이에서 지낸 지도 제작자, 지도에서 사라진 공상 오염 구역에서의 생환, 시각과 위치의 기록, 성맥 접속, 신비 지각 및 분석, 의심과 침착한 관찰, 확인을 거듭해 결정이 늦어지는 습관, 조사 1팀 요원과의 현장 만남, 돌아올 길을 먼저 확보한다는 약속, 현장 안정 키트와 표시 도구, 큰 힘을 쓸 때의 기억 마모입니다. 사라진 구역의 정체나 조사 1팀 합류 이후의 사건은 확정하지 않았습니다.

`assets/vanished-route.jpg`, `assets/cartographer-back.jpg`, `assets/map-kit.jpg`는 내장 ImageGen으로 새로 만든 삽화입니다. 웹용 JPEG로 변환했으며 생성 원본 PNG는 ImageGen 생성 폴더에 남겨 두었습니다. 프롬프트의 핵심 장면은 다음과 같습니다.

- 산길: “비가 지난 산과 숲의 길, 나무 사이의 설명할 수 없는 빈틈, 오른쪽 바위 위의 글자 없는 지도·나침반·연필. 왼쪽에 제목용 어두운 여백, 숯색·슬레이트 청록·양피지 색, 글자·로고 없음.”
- 인물 분위기: “안개 낀 산길에서 뒷모습만 보이는 20대 남성 지도 제작자. 얼굴과 구체적인 외형은 보이지 않고 지도통과 현장 가방을 착용. 길 앞쪽의 미묘한 이상현상, 글자·문장·무기 없음.”
- 보급품: “지도와 나침반, 현장 표시 도구, 작은 응급 키트, 빈 ID 카드와 수첩이 놓인 현장 작업대. 창밖의 젖은 산림, 절제된 짙은 녹색과 청록색, 글자·로고 없음.”

`assets/erac-logo.png`는 기존 Laika/CYOA 프로젝트의 ERAC 문장을 재사용했습니다. 이름과 사진이 정해지면 두 HTML의 미정 표기와 분위기 삽화를 교체할 수 있습니다.
